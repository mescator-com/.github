<h1 align="center">MESCATOR</h1>

<p align="center"><strong>The ERP says it is finished. The floor knows it is not.</strong></p>

MESCATOR closes the gap between what the system believes and what is actually happening on the line. Works orders that carry plan and actual, machine signals read where they already exist, traceability you can act on, and promise dates built from real throughput. Built on sovereign open source, on your own infrastructure, and never in the control path.

## What it does

- **Works orders with plan and actual.**
- **Machine data from what you already run.** Reads the floor, never controls it.
- **Genealogy you can query**, and quality on the order, not in a binder.
- **Promise dates from real throughput.** Runs offline, on your premises.

## For Microsoft 365

- **[Mescator for Power Platform](https://mescator.com/microsoft-power-apps)** — a free version of Mescator built on Microsoft Power Apps (a model-driven app) and Microsoft Dataverse, installed into your own Microsoft Power Platform environment, with the data staying there.
- **[Mescator Code](https://mescator.com/microsoft-power-apps-code)** — the same data in an interface designed for Mescator, built as a Microsoft Power Apps code app.
